existence dependency : we have a rel schema r where for all functional
dependencies on r , the functional dependency x-->y such that if operationally y is deleted , so is x. y is dominant entity

types of functional dependencies :
  1. full functional dependency--- all non key attributes are wholly dependent on key attribute
  2. partial functional dependency --- some non key attributes are dependent on key attribute and remaining non key attributes
    are dependent on key attribute and on some other non key attributes
  3. transitive dependency---if attributes in key col of 1 rel correspond to the key atributes in col of another rel
  4. multi valued dependency --- in 4 NF
  5. join dependency --- in 5 NF

Transactions --- a transaction is a unit of program execution that accesses and –or possibly updates various data items . Acid properties of a transaction are : Atomicity --- either transaction executes in entirety or none executes at all
Consistency --- state of database remains same both before and after transaction despite system changes
Isolation --- despite concurrent execution of transactions , each transaction proceeds independently of others despite system changes
Durability --- any modifications made to database as a result of transaction persist even if there are system changes
